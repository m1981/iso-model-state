# <projekt> — wzorzec wyglądu

Wiążący wzorzec interfejsu. Zmiana wzorca wymaga decyzji (DEC); odstępstwo w implementacji jest na liście eskalacji.

## Zasady

1. Najpierw makieta HTML (samodzielny plik), potem akceptacja (DEC z cytatem), dopiero potem kod.
2. Zaakceptowana makieta trafia tutaj jako `E-nn-<nazwa>.html`; odrzucone warianty do `../ui-mockups/` z dopiskiem, którą DEC je odrzucono.
3. Wszystkie wartości (kolory, czcionki, rozmiary, odstępy, stany, teksty) w tabeli poniżej, jedno źródło dla kodu (np. moduł `theme`).
4. Po zmianie interfejsu agent uruchamia program i prosi o zrzut; porównanie zrzutu ze wzorcem zapisuje w `MANUAL.md`.
